# Domain Docs

CodeCairn is a single-context repository.

Before implementation, read root `CONTEXT.md` and the ADRs that touch the
module. Use the exact glossary vocabulary in issue titles, tests, interfaces,
and reports. If a proposal contradicts an ADR, state the conflict rather than
silently overriding it.

Use [`../INDEX.md`](../INDEX.md) to locate maintained architecture, runtime,
operations, evaluation, evidence, and release documents. Generated evidence
bundle prose reports published measurements; it does not replace domain or
architecture contracts.
