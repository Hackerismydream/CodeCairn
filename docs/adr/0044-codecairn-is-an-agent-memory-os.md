# CodeCairn Is an Agent Memory OS

CodeCairn owns local durable memory independently from Codex, Claude Code,
Raven, or any other agent runtime. Version 0.1 ships one implicit Coding
Profile because repository-scoped coding is the first complete product
scenario; it does not introduce a dynamic profile framework.

The Coding Profile may retain the existing `repo_key` implementation internally
as its Memory Namespace key. Product positioning does not require a broad
namespace refactor before release.
