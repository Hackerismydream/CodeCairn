# Version 0.1 Has Four Coding Memory Types

The Coding Profile exposes four durable memory types:

1. Task Experience records one task's goal, relevant actions, and outcome.
2. Repository Knowledge records reusable architecture, conventions, commands,
   constraints, and solutions.
3. User Preference records a user-expressed working or output preference.
4. Work State records an active Workstream's goal, progress, blockers, and
   next step.

Agent Traces and Evidence Facts are Source Layer records, Supersession is an
Evolution Layer relation, and Recall Context is a derived Recall Layer view.
The former Debug Episode, Failed Command, and Verified Fix types become facets
of Task Experience. Repository Convention becomes a category of Repository
Knowledge, and Conversation Episode becomes a source/experience adapter used
by evaluation rather than a fifth product type.
