# Memory Is Layered from Sources to Evolved Knowledge

CodeCairn models memory as five authorities: Source retains imported material
and deterministic observations; Experience records bounded task narratives;
Knowledge stores reusable repository knowledge, user preferences, and active
work state; Evolution records which memories supersede others; Recall compiles
active memory into task-shaped context.

Every derived layer keeps lineage toward its supporting layer. Public memory
types are therefore not presented as the complete ontology, and Recall Context
never becomes another durable truth source.
