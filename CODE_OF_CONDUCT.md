# Code of Conduct

CodeCairn expects technical discussion to be direct, specific, and
professional. Critique claims, designs, code, and evidence; do not attack,
threaten, harass, discriminate against, or expose private information about
people.

Examples of expected behavior include giving reproducible evidence, stating
uncertainty, respecting attribution and licenses, and accepting a maintainer's
decision to keep the project within its documented scope. Unacceptable
behavior includes impersonation, sexualized or discriminatory conduct,
doxxing, deliberate secret disclosure, and sustained personal disruption.

Repository maintainers may edit, hide, lock, or remove contributions and may
restrict participation when repository activity violates this policy. For a
sensitive report, use the private route described in
[`SECURITY.md`](SECURITY.md); never publish private details merely to report
conduct. No response time or external arbitration process is promised.

This policy applies to the repository and to public spaces where someone is
representing CodeCairn.
